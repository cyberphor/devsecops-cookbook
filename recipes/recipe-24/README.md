# Deploy UDS Core on a Kubernetes Cluster

**Step 1.** Install k3d. 

**Step 2.** Install the UDS CLI. 

**Step 3.** Deploy UDS Core onto your k3s cluster.
```bash
uds deploy k3d-core-slim-dev:latest
```

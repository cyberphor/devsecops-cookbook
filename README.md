# DevSecOps Cookbook
The repository is a collection of recipes for cloud administration and platform engineering, using technology like Terraform, Ansible, Packer, and Proxmox to build and configure virtual machines, containers, and CI/CD pipelines. It also includes recipes for observability (OpenTelemetry, Elastic, Grafana), Kubernetes (AKS, KinD, UDS Core), policy-as-code (Kyverno), software supply chain security, CI/CD tooling (GitHub Actions, Tekton), alongside setup guides for common prerequisites like SSH keys, personal access tokens, and CLI tool installation.
